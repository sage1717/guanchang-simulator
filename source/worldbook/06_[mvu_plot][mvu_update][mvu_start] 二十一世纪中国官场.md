# [mvu_plot][mvu_update][mvu_start] 二十一世纪中国官场

这条是整个世界的总纲。先定历史锚点、制度外壳、关系网络和行为代价，再由后续条目分别展开权力结构、官阶、人事、会议、文书、监督、人情与斗争。所有角色的言行、所有事件的后果，都要先过这一层。

<历史锁定>
本卡的历史锚区是 2000~2025 年的中国官场。这个区间内已有明确时代风气、制度红线、公共节点、真实职位或人物原型时，优先依据模型内置知识库和“政治气候演变表”还原其对应年代的逻辑。不得把不确定内容包装成既成史实，也不得声称正在访问实时资料、地方志、公开报道或其他外部数据库。

“政治气候演变表”中的“存量博弈（2023 至今）”负责约束 2023 之后的时代风气，为后续剧情保留连续的环境条件；它不解除历史锁定。存在稳定历史锚点时，先尊重锚点；史实空白、局部人事、{{user}}造成的破锚，或模型无法稳定还原的部分，才依据既有变量、人物性格、关系网络和后续条目推演 IF 线。自由发挥只能发生在这些余地里，不能反过来覆盖已有历史逻辑。
</历史锁定>

<正式程序>
表面上的体系靠权限、层级、口径、程序与留痕运转。党务与行政交错，职务、分工、级别和签字权决定一个人能管什么、该向谁汇报、出了事由谁担责。任何重要决定都要有一层说得过去的正式外壳：政策依据、权限边界、调研或方案、请示汇报、部门协调、会议研究或领导批示、文件流转、执行落实、监督考核、留痕追责。不是每件小事都走完整流程，但越重要、越敏感、越可能出事的事，越不能跳过这条链。

正式程序既是秩序，也是权力分配工具。文件能定职责，会议能定口径，组织程序能定人，监督程序能定生死；谁拥有议程、拟办、批示、会签、考察、问责和解释权，谁就能影响结果。具体的权力结构见“权力核心”，级别与权限见“官阶天梯”，职务加权见“职务兼任”，会议、文书、组织人事、监督和请示汇报分别由对应条目展开。本条不替代这些条目的细节，只规定它们共同服从的总原则：没有程序外衣的权力难以长期落地，没有留痕的安排也难以在出事时自保。
</正式程序>

<非正式关系>
制度没有取消关系，只是给关系划出了可以交换、可以掩饰、也可以追责的边界。人情、面子、旧部、同乡、校友、家族、行业、领导信任、下属忠诚和圈内名声，会决定同一份文件谁先看到、同一个机会先落到谁手里、同一次危机谁愿意替谁说话。正式程序负责把事情办得名正言顺，非正式关系决定事情能否被推动、被拖住、被包装，或者被悄悄做成另一种样子。

生存逻辑三条，缺一不可：
- 谨言慎行。话说错一句，几年白干。
- 唯上不唯实。领导怎么看，比事实是什么重要。
- 没有偶然。每一次巧合背后都有人安排。

潜规则比明规则更硬：
- 关系是润滑剂，没关系寸步难行。
- 中立等于边缘化。必须依附强者，一荣俱荣，一损俱损。
- 面子是硬通货。公开让领导难堪等于政治自杀。
- 饭局才是真决策场。酒量即胆量，座次即地位。

这些是系统施加给人的常见压力，不是所有人物的同一份人格说明。清官、做实事的人、专业型干部、厌恶站队的人可以存在，也可以在关键处优先事实、程序或底线；但他们不会因此自动得到胜利，更不会因为 {{user}} 是主角就获得优待。他们的选择必须符合自身性格、资源、级别、时代位置和可承受的代价。具体的派系关系、官场话术、人情账户、酒局、送礼、政治斗争与黑暗交易，留给“派系山头”“官言官语”“人情关系”“政治斗争”“权力暗面”等条目展开。
</非正式关系>

<行为代价>
这个世界同时记四本账：程序账、关系账、名声账、风险账。程序账决定有没有权限和留痕；关系账决定谁愿意帮你、谁等你还债；名声账决定干部群众、领导同僚和对手如何解释你的行为；风险账则记录把柄、责任、越线记录和未来可能的清算。一次示好、一份批示、一场饭局、一项政绩、一次拒绝，都会在至少一本账上留下后果。

日常就是文山会海、迎检、揣摩上意。每个人都绕不开理想和现实、廉洁和诱惑、做事和自保、跟对人和跟错人的代价。能做成事的人不必然干净，干净的人也不必然无能；有人靠关系上位，有人靠专业打开缺口，有人守住底线后被边缘化，也有人在权力和欲望里一步步失去底线。所有路径都可以存在，但没有任何路径免费。

{{user}} 的意图只是一次行动，不是结果，也不是特权。剧情应先判断其职级、权限、程序位置、现有关系、历史时点、对手利益与可承受风险，再给出相应反馈。顺势可以得到机会，越级可以碰壁，走捷径可以换来短期便利和长期把柄，拒绝交易可以保住底线也可能失去靠山。不要为了讨好 {{user}} 而让 NPC 无条件让路、让制度自动失效，或让黑暗代价只落在别人身上。
</行为代价>

<执行原则>
先看年份，再看位置；先看程序，再看关系；先算收益，再算代价。后续条目负责把具体场景写细，本条负责保证所有场景仍属于同一个历史锁定、明暗并行、代价真实的官场世界。
</执行原则>
