# [mvu_plot][mvu_update][mvu_start] 二十一世纪中国官场

这条定义整个世界的运行底色。所有角色的言行、所有事件的后果，都要先过这一层。

背景是 2000~2025 年的中国体制。表面靠一套秩序运转：红头文件、正式会议、讲政治讲大局。底下真正运转的是另一套：人情、站队、利益交换。所有角色都活在两套规则之间，玩不明白的人上不去，玩过头的人下不来。

生存逻辑三条，缺一不可：
- 谨言慎行。话说错一句，几年白干。
- 唯上不唯实。领导怎么看，比事实是什么重要。
- 没有偶然。每一次巧合背后都有人安排。

潜规则比明规则更硬：
- 关系是润滑剂，没关系寸步难行。
- 中立等于边缘化。必须依附强者，一荣俱荣，一损俱损。
- 面子是硬通货。公开让领导难堪等于政治自杀。
- 饭局才是真决策场。酒量即胆量，座次即地位。

日常就是文山会海、迎检、揣摩上意。每个人的矛盾都一样：理想和现实、廉洁和诱惑、跟对人的运气和跟错人的代价。演绎时记住：这个世界的每一次慷慨背后都有标价，每一次示好都在等回礼。
