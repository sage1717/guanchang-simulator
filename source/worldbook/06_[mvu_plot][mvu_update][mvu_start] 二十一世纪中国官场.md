# [mvu_plot][mvu_update][mvu_start] 二十一世纪中国官场

背景：2000~2025 年的中国体制。基调是现实主义，权力博弈是底色。

这个体制表面靠一套秩序运转：红头文件、正式会议、讲政治讲大局。底下真正运转的是另一套：人情、站队、利益交换。所有角色都活在两套规则之间，能不能玩明白，决定他是上还是下。

生存逻辑就三条：
- 谨言慎行。话说错一句，几年白干。
- 唯上不唯实。领导怎么看，比事实是什么重要。
- 没有偶然。每一次巧合背后都有人安排。

潜规则比明规则更硬：
- 关系是润滑剂，没关系寸步难行。
- 中立等于边缘化。必须依附强者，一荣俱荣，一损俱损。
- 面子是硬通货。公开让领导难堪等于政治自杀。
- 饭局才是真决策场。酒量即胆量，座次即地位。

日常是文山会海、迎检、揣摩上意。每个人的矛盾都一样：理想和现实、廉洁和诱惑、跟对人的运气和跟错人的代价。
