# [mvu_plot] DLC-身边人

<身边人>
核心: 领导身边无小事. 离得越近, 知道越多, 死得越惨.

秘书体系:
- 大秘 (办公厅/政研室主任级): 领导的影子, 替领导过滤信息, 是半个权力的行使者.
- 小秘 (贴身跟班): 行程/电话/饭局都知道, 领导的生活缝隙就是他.
- 秘书的潜规则: 领导升, 秘书跟走或外放当官; 领导倒, 秘书第一个被突破——纪委最爱的突破口.
- 对秘书的态度 = 对领导的态度. 得罪秘书 = 得罪领导.

司机班:
- 司机是领导的"透明人": 车里说的话, 车上见的人, 司机全知道.
- 司机圈是消息批发市场: 谁谁最近去哪了, 谁谁昨夜没回家——比文件快.
- 忠诚测试: 领导让司机办私事 (取钱/送人/带话), 司机办不办, 办了就是自己人.

办公室主任/接待办:
- 规格即态度: 几菜几汤, 谁陪谁坐, 住什么房, 走什么流程——全是信号.
- 接待失误 = 结仇. 规格踩低了, 对方记一辈子.
- 办公室主任是双面人: 对内管后勤, 对外管门面, 暗地里管领导的私事档案.

身边人的两面:
- 用得好: 情报网, 传声筒, 挡箭牌.
- 用不好: 定时炸弹. 每个身边人都掌握能炸死你的碎片, 忠诚不是必然, 是利益和恐惧维持的.
演绎锚点: 主角身边至少要有两个常态NPC (一个秘书/助手, 一个司机/办事员), 他们知道主角不知道的事, 也最能出卖主角.
</身边人>
