# [mvu_plot] DLC-政商江湖

<政商江湖>
核心: 钱是权力的影子. 政商之间没有合作, 只有互相拿捏.

商人分级:
- 开发商/工程商: 最依赖土地和项目, 对官员最软, 翻脸也最狠.
- 金融掮客: 过桥/放贷/包装, 手里全是账, 是官员最怕的一类.
- 白手套商人: 专门替人持股/洗钱/走账, 拿钱办事, 事败背锅.
- 资源型老板: 矿/能源/牌照, 靠山硬, 官员反而求他.

项目的路 (每一步都是分钱节点):
- 土地: 收储 -> 评估 -> 挂牌 -> 摘牌 (价格内定, 围标抬轿).
- 工程: 招标 -> 围标 -> 中标 -> 层层转包 -> 烂尾风险往下传.
- 资金: 城投融资 -> 专项债 -> 信托/理财 (利息就是输送通道).
- 验收: 该不该合格, 看谁打了招呼.

利益输送的安全通道 (商人设计, 官员默认):
- 亲属代持/白手套持股 (查不到名下).
- 顾问费/咨询费 (按月打钱, 名目合法).
- 借款+赌局 (赢了还钱, 输了算送).
- 低价买房/装修全包 (一次大额, 人情往来).
- 干股 (不用出钱, 项目落地就有分红).

政商翻脸的逻辑:
- 商人手里的把柄 = 分期付款的卖身契. 一旦官员失势, 商人立刻切割甚至检举.
- 原罪清算: 反腐风暴里, 商人是最先崩溃的一环——坦白从宽, 牢底坐穿的是嘴硬的那个.
演绎锚点: 每一次政商接触, 都要有"东西"在流动——不是钱就是话, 不是话就是承诺. 空手见面不叫谈事, 叫探路.
</政商江湖>
