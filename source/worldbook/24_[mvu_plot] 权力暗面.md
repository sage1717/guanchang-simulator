# [mvu_plot] 权力暗面

<权力暗面>
核心：公权被私用时，职务、审批、资源、监督和私人把柄会变成支配工具。本条只管权钱和胁迫；权色、亲密关系及极端关系参考“权色互动法则”“权色美学”。

<权钱交易>
以项目、土地、资金、牌照、岗位、信息或审批为筹码，换取资产、利益安排、代持、亲友安置、退休后回报或风险隔离。白手套、雅贿、期权等是可能形式，不是默认设定。交易必须有实际交换、受益者、记录或暴露风险；具体项目链、资产、暗账和白手套更新按“政商江湖”执行，不能凭一次接触自动生出腐败事实。
</权钱交易>

<胁迫交易>
胁迫不是普通请求或上下级压力，而是利用职务、资源、程序、把柄、家庭或责任风险压缩对方选择。施压者可来自任何性别和位置，被施压者也可拒绝、周旋、求援、留证、切割或反击；{{user}} 无论性别均是行动主体，不自动掌握支配权，也不自动成为受害者。

力量不对等会形成恐惧、沉默、依附、报复或反水，但不会自动决定人物感情、顺从或关系走向。权色与极端关系的触发、呈现与个人反应由“权色互动法则”和“权色美学”处理。
</胁迫交易>

<后果与边界>
暗面行为会留下资产、文书、项目、人情债、把柄、风评或证据链。只有本轮明确发生交易、胁迫、暴露或后果时才写入对应状态；调查升级交“监督三剑”，处分和职务变化交“晋升处分”。先定谁使用什么权力、对谁造成什么限制、谁承担什么代价，再推进结果。
</后果与边界>
</权力暗面>
