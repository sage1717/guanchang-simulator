# [mvu_plot][mvu_update][mvu_start] 政治气候演变表

这条管时间锚定：时代决定生死。2005 年的能吏，到 2015 年可能就是阶下囚。同样一件事，在不同年份性质完全不同，演绎时先看年份再定性。

<变量与历史边界>
政治气候只由当前日期的“年”自动计算，不得手动改写。初始化和每轮更新时，应先根据年份落入的阶段判断环境，再让重大事件、中央动态、省内风向、本地新闻、圈内传闻和个人风评与该阶段一致。政治气候本身不是一条可随意改动的剧情结果，而是判定剧情、人物选择、资源流向和风险等级的前提。

四个阶段名称与年份边界固定对应变量映射：狂飙年代（2000-2012）、雷霆震荡（2013-2017）、大考淬炼（2018-2022）、存量博弈（2023 至今）。历史锚区内有稳定时代节点、政策环境、职位或人物原型时，优先依据模型内置知识库还原；史实空白、局部人事、{{user}}破锚后的后果，才依照本条和后续规则推演 IF 线。不得把未知的后续任免、案件或人物结局伪装成既成事实，也不得声称正在查询实时资料。
</变量与历史边界>

<经济基础与官场逻辑>
经济基础决定上层建筑。财政能力、产业结构、增长方式、土地与项目资源、债务压力和可分配利益，决定地方政府最看重什么，也重塑干部的政绩标准、组织考核、资源争夺、关系网络和反腐风险。官场不是脱离经济运行的纯人事游戏：钱从哪里来、项目靠什么落地、财政能否支撑、旧账由谁承担，都会变成人事安排、派系消长和个人命运的一部分。

本条只解释宏观经济如何改变官场激励，不替代具体经济活动。项目、土地、融资、工程、商人和利益输送的具体机制由“政商江湖”展开；省会、经济强市、资源型地区和边缘城市的差异由“省域版图”展开；个人能否调配资源、财政、土地和编制则由能力与职务条目处理。演绎时先判断所处阶段的经济底盘，再判断这座城市、这项项目、这个人物具体处在哪种资源与权力关系里。
</经济基础与官场逻辑>

狂飙年代（2000-2012）
经济底盘：扩张、投资、土地、项目和增长速度被视为地方竞争力。财政与政绩高度依赖能否拿到项目、拉来资金、做大产业和铺开建设，资源快速流动，也给寻租、围标、利益输送和账外关系留下空间。

官场逻辑：唯 GDP 论。能拉来项目、搞高增长就是"有魄力"，程序违规被默认为会办事。饭局是权力祭坛，茅台是硬通货，夜总会是第二办公室，灰色地带极度宽容。关键词：招商引资、土地财政、大拆大建、闷声发财。雷区：群体事件、矿难、上访。

行动判定：敢跑项目、能协调资源、会包装政绩的人容易获得窗口；但越是靠土地、工程、矿产、融资和关系堆出的成绩，越会留下未来可被追溯的程序账、利益账和责任账。人物可以清白、专业或谨慎，但必须面对“扩张优先”的组织压力。

雷霆震荡（2013-2017）
经济底盘：此前高速扩张留下的项目、融资、关系和利益网络没有自动消失，旧账反而开始成为政治风险。资源仍然重要，但拿资源、分项目、维系关系的方式开始被重新审视，过去的“会办事”可能变成日后的违规证据。

官场逻辑：八项规定加高压反腐。讲规矩压倒一切，功劳再大碰红线必死。吃喝收礼从"豪爽"变成"顶风作案"。高档会所关门，茅台装进矿泉水瓶，官员连同学聚会都躲。心态是惊弓之鸟，普遍"为官不为"——不做不错。关键词：打虎拍蝇、巡视组、回头看。雷区：公款吃喝、收礼、站错队。

行动判定：机会来自程序修复、风险切割、专业执行和在清理旧关系时保住自身；风险来自替人背书、替旧项目签字、为关系网遮掩或误判监督强度。人情没有消失，只是更隐蔽，也更容易从助力变成把柄。

大考淬炼（2018-2022）
经济底盘：资源和干部注意力被集中到重大专项、民生任务、风险处置和可量化的执行结果上。单纯追求规模不再足够，能否把任务拆解、把资源落地、把结果做成可检查、可汇报、可留痕的成果，决定一个人是否被看见。

官场逻辑：政治站位压倒一切，忠诚和执行力优先于创造力。脱贫攻坚、扫黑除恶、疫情防控三场硬仗，形式主义回潮：填表打卡、5+2 白加黑。运动式治理常态化，环保一刀切、防疫层层加码都是政治任务。关键词：政治站位、留痕、督导组。

行动判定：做实事、能组织、能完成专项的人可以获得上升空间，但必须把成果纳入正式口径；只做事不汇报、只讲专业不顾政治时点，也可能被视为不懂规则。风险来自层层加码、数据失真、任务转嫁、事故失控和留痕无法自证。

存量博弈（2023 至今）
经济底盘：扩张空间收缩后，地方首先面对的是财政承压、存量资产、既有项目、债务责任和有限资源的重新分配。2026 仍处在这一变量映射区间内：剧情可以围绕化债、清理旧账、接盘重组、压缩开支、筛选项目和守住风险底线展开，但没有稳定历史锚点的具体后续事实必须按既有变量和 IF 逻辑推演。

钱没了，规矩更紧。地方财政枯竭，土地卖不动，主官从"花钱"变"找钱、化债"。严控开支、缩编制、降薪，基层过紧日子。倒查二十年，退休也不安全，金融、医疗领域深挖。招商极度挑剔且没钱配套。关键词：地方债、化债、金融反腐、新质生产力、防风险。雷区：新增隐性债务、政绩工程烂尾、触碰金融红线。

行动判定：机会不再只来自开新摊子，也来自处理遗留项目、压降风险、整合资源、接住烂摊子并把它变成可交代的结果；风险则集中在隐性债务、项目烂尾、资金链、旧账追溯和被迫替前任背责。做事的人仍有空间，但任何扩张、承诺和投入都必须先回答钱从哪里来、谁来担责、失败后谁来收场。

<执行原则>
先看年份，再读自动得出的政治气候；再用该阶段的经济基础判断资源、任务、关系和风险；最后才生成六项时空舆情、人物选择与剧情结果。阶段规则约束环境，不替代人物性格：同一时期可以有清官、技术干部、投机者、关系户和失势者，但他们的选择都必须承受该阶段的经济与政治后果。

年份越靠后，灰色操作越危险，台面文章越要足。角色的每一步都得先算年份的账——同一杯茅台，2005 年是豪爽，2015 年是找死。
</执行原则>
