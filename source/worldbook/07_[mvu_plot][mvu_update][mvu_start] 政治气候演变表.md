# [mvu_plot][mvu_update][mvu_start] 政治气候演变表

时代决定生死。2005 年的能吏，到 2015 年可能就是阶下囚。年份不同，同样的事性质完全不同，演绎时必须锚定当下年份的风气。

狂飙年代（2000-2012）
唯 GDP 论。能拉来项目、搞高增长就是"有魄力"，程序违规被默认为会办事。饭局是权力祭坛，茅台是硬通货，夜总会是第二办公室，灰色地带极度宽容。关键词：招商引资、土地财政、大拆大建、闷声发财。雷区：群体事件、矿难、上访。

雷霆震荡（2013-2017）
八项规定 + 高压反腐。讲规矩压倒一切，功劳再大碰红线必死。吃喝收礼从"豪爽"变成"顶风作案"。高档会所关门，茅台装进矿泉水瓶，官员连同学聚会都躲。心态是惊弓之鸟，普遍"为官不为"——不做不错。关键词：打虎拍蝇、巡视组、回头看。雷区：公款吃喝、收礼、站错队。

大考淬炼（2018-2022）
政治站位压倒一切，忠诚和执行力优先于创造力。脱贫攻坚、扫黑除恶、疫情防控三场硬仗，形式主义回潮：填表打卡、5+2白加黑。运动式治理常态化，环保一刀切、防疫层层加码都是政治任务。关键词：政治站位、留痕、督导组。

存量博弈（2023 至今）
钱没了，规矩更紧。地方财政枯竭，土地卖不动，主官从"花钱"变"找钱、化债"。严控开支、缩编制、降薪，基层过紧日子。倒查二十年，退休也不安全，金融、医疗领域深挖。招商极度挑剔且没钱配套。关键词：地方债、化债、金融反腐、新质生产力、防风险。雷区：新增隐性债务、政绩工程烂尾、触碰金融红线。

玩法提示：年份越靠后，灰色操作越危险，台面文章越要足。角色的每一步都得先算年份的账。
