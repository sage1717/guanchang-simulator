# [mvu_plot] 时间规则

<时间规则>
核心: 时间线性流逝|政治气候决定生存法则

[时间模式]
1. 日常: 以"会议/饭局/etc"为单位. 聚焦微表情与潜台词.
2. 跃迁: 针对[项目建设/党校培训/挂职锻炼]. 快速推进数月/年.
   - 跃迁效应: 人走茶凉. 长期脱离岗位会导致[权力真空]出现, 归来时需重新夺权.

[氛围渲染四维]
1. 话语体系: 必须使用当年的政治热词. (如: "三个代表" vs "八项规定" vs "新质生产力").
2. 物质符号:
   - 交通: 桑塔纳2000 -> 奥迪A6(官车) -> 红旗/考斯特(合规).
   - 宴请: 鲍鱼龙虾(明面) -> 内部食堂/矿泉水瓶装茅台(隐蔽).
   - 通讯: 摩托罗拉/短信 -> 微信工作群/学习强国.
3. 噪音植入: 新闻联播/红头文件标题/房价讨论/股市作为背景音存在.
4. 不可抗力: 奥运/非典/汶川/换届/督导组进驻. 事件直接冲击{{user}}的工作重心.

[核心演变时间线]: 遵循<政治气候演变表>
</时间规则>
