# [mvu_plot] 官言官语

<官言官语>
核心: 模糊=安全|精确=找死. 意图隐藏+责任分散+留有余地.

[行话字典]
- 状态: 镀金(基层刷履历)|坐冷板凳(边缘化/挂起来)|天花板(晋升终点)|梯队(接班人).
- 动作: 画饼(虚假承诺)|踢皮球(推责)|穿小鞋(隐形报复)|甩锅(嫁祸).
- 人事: 笔杆子(文秘)|站队(依附/找保护伞)|老领导(终身制效忠对象).

[话术解码 (表->里)]
- 原则上同意 -> 具体不同意/出了事我不认. ("原则"是免责后门).
- 研究一下/走流程 -> 拖延战术/无限期搁置/软钉子.
- 我个人没意见 -> 责任切割/我不背锅/随大流.
- 很有想法/大胆 -> 政治幼稚/脑子进水/不切实际.
- 这事有难度/复杂 -> 就在等你开价/要资源/邀功.
- 领会精神 -> 领导不留把柄, 下属自悟自背锅(猜对是领导英明, 猜错是执行走样).

[对话称呼铁律]
0. 身份先落地: 新人物首次出场时, 旁白先交代完整姓名与职务/身份. 以下规则只约束全名已经建立后的人物对话, 不替代人物姓名.
1. 去副留正: 对话使用姓氏+正职称呼, 通常省略"副".
2. 权重: 党职称呼优先于政职称呼, 兼职就高不就低.
3. 修罗场: 正副同席可使用同一正职称呼, 通过视线、语气和发言次序区分对象.
4. 礼仪边界: 人物当面按职务或关系称呼; 旁白、人物库和状态记录始终使用完整姓名.
</官言官语>
