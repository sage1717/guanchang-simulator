# [mvu_update] 变量更新规则 (别关)

<变量更新规则>

  全局铁律:
    - 地名与姓名铁律: 所有地名(省/市/县/区/单位/院校/街道/楼盘)一律使用现实真实地名(如江苏省、淮安市、南京市鼓楼区); 人物姓名一律使用符合年代与身份的完整化名(姓+名), 真实原型只保留履历、性格和关系锚点.
    - 跨模块人物引用铁律: 人物库record ID、姓名字段、当前场景.在场人物、关系索引及机遇与危机中的人物引用, 统一使用人物库中的同一完整姓名; 职务、姓氏简称和昵称只写入叙事或关系描述.
    - 真实事件优先: 涉及政策/会议/事件一律以真实历史事件为准(两会/换届/巡视/疫情等).

  ## === 时空舆情 === ##
  时空舆情:
    当前日期:
      type: |-
        {
          年: number; // 2000~2100
          月: number; // 1~12
          日: number; // 1~31
          星期: '周一' | '周二' | '周三' | '周四' | '周五' | '周六' | '周日';
        }
      check:
        - 场景推进、休息、旅行、会议结束后更新
        - 星期需与年月日对应（可由LLM自动推算）
        - 跨日事件需说明时间流逝原因

    当前时间:
      format: "HH:MM"（24小时制）
      check:
        - 每个场景转换、会议/饭局/约谈等事件节点后更新
        - 官场日常通常从08:30开始，深夜密谈可至凌晨

    当前地点:
      check:
        - 场景转换时更新
        - 格式建议：省份+城市+具体地点（如"江苏省南京市·省纪委大楼第三谈话室"）

    重大事件:
      check:
        - 当发生国家级/省级重大事件时更新
        - 优先使用真实历史事件（建党节、两会、换届、疫情等）

    中央动态:
      check:
        - 反映当前年份中央层面的政策风向
        - 需与政治气候保持一致（如"雷霆震荡"期应体现八项规定、巡视组等）

    省内风向:
      check:
        - 反映省级权力格局变化、派系博弈态势
        - 涉及一把手/省长等核心人物时更新

    本地新闻:
      check:
        - 反映地市级舆情、民生热点、信访动态
        - 与{{user}}当前案件/工作相关时优先更新

    圈内传闻:
      check:
        - 体制内小道消息、官场八卦、人事调动风声
        - 需保持模糊性和不确定性（"据说"、"风传"、"怕是要"等话术）

    个人风评:
      check:
        - 反映{{user}}在官场圈内的口碑形象
        - 重大事件（办成大案/作风问题曝光/得罪要人）后更新

  ## === 当前场景 === ##
  当前场景:
    场景类型:
      ref: 机关办公/会议场所/饭局酒桌/私密会所/出差途中/绯色交互/家中私宅/公共场合/隐秘据点/医院病房/审讯场所/看守所内/车内密谈
      check:
        - 场景转换时更新
        - 优先根据剧情实际选择，不限于参考取值

    场景速写:
      check:
        - 50-150字的场景描绘，包含环境细节、氛围、关键物件
        - 需与气氛基调呼应

    气氛基调:
      ref: 严肃正式/觥筹交错/暧昧旖旎/淫靡色情/打破禁忌/剑拔弩张/轻松随意/压抑沉闷/暗流涌动/悲伤哀悼/惊恐慌乱/如坐针毡/虚与委蛇
      check:
        - 场景转换或气氛发生显著变化时更新
        - 优先根据剧情实际选择

    在场人物:
      type: string[]
      check:
        - 列出当前场景中所有在场人物的完整姓名
        - 人物进场/离场时更新
        - 只记录实际身处当前场景、能够当面互动的人物
        - 电话、短信、微信中的联系人属于远程通讯对象；只有本人实际到场后才加入本字段

    潜在议题:
      check:
        - 当前场景可能涉及的核心话题/冲突点
        - 为剧情推进提供方向指引
